## 1. 背景与目标

做一个"网上很火"的交互式个人简历网站，但**不投真实简历**：以虚构人设演示完整交互，作为可供任何人复用的模板。任何人克隆后只改 `src/data/resume.ts` 一份文件，就能得到自己的交互式简历。

成功标准：

1. 评委点开公网链接即可访问，3 分钟内理解"这是谁的什么"，并愿意多玩 1 分钟。
2. 内容与展示解耦：数据文件之外不含任何个人文案。
3. 在 11/29 前完成部署，11/30 18:00 前完成论坛提交。

## 2. 范围

### 做

- 单页交互式简历，多模块（关于 / 经历 / 项目 / 技能 / 联系方式等，具体交互形态由设计决定）。
- 虚构人设完整内容，覆盖全部模块。
- 单一数据源 `src/data/resume.ts`，带 TypeScript 类型。
- 纯前端静态站点，部署到 Qoder Sites，公网可访问。
- 移动端可用、键盘可用、减弱动效降级。
- 作品帖文案与截图（Qoder 起草，用户发布）。

### 不做

- 站内可视化编辑器、登录、数据库、后端函数。
- 运行时调用任何 AI API。
- 真实个人信息（姓名、电话、邮箱、学校、公司）。
- 外部 CDN 依赖、自动播放音频。
- 多语言、多套主题切换（除非设计明确列入且不影响排期）。

## 4. 技术架构

- 技术栈：Next.js 16（App Router）+ React 19 + TypeScript + Tailwind CSS 4，`output: "export"` 静态导出到 `out/`。
  - 2026-11-25 变更：原定 Vite + React，用户确认保留既存 Next 工程，避免 5 天内重写。
- 构建：`npm run build` 生成 `out/`；不引入服务端能力、API Route 或 middleware。
- 部署：Qoder Sites 托管 `out/` 静态产物。部署后必须验证 `/_next/` 资源与深层链接。
- 路由：当前仅 `/`（与 `/_not-found`）；不新增依赖服务端 rewrites 的路由。
- 字体：系统字体栈；禁止 `next/font/google` 等外部字体服务。
- 样式扫描：Tailwind 自动扫描需排除构建产物 `out/`（已用 `@source not`），否则旧产物会反向污染构建。
- 测试：Vitest（`npm test`），至少覆盖窗口生命周期与数据契约。
- 依赖：只增必要依赖；新增依赖需在 `STATUS.md` 记录原因，不升级大版本。

## 5. 数据契约

当前实现（2026-11-25）：

- 内容文件：`public/resume-config.json`。
- 类型定义：`src/types/resume.ts` 的 `ResumeConfig`（meta / about / education / experience / projects / writing / customSections / theme / i18n）。
- 加载：`src/hooks/useConfig.ts` 在客户端 fetch 该 JSON，失败时回退默认配置。

规则：

- 所有展示文案（正文、标题、简介、标签）只允许存在于该 JSON；组件内只放 UI 文案（如"关闭""发送邮件"）。
- **G1 遗留问题**：`src/lib/config.ts` 的 `defaultConfig` 复制了全部正文，形成双源，G2 必须消除（只保留结构兜底或删除）。
- 演示内容必须是**完整虚构人设**；当前"你的名字 / yoursite.com / your-github-username"占位文案必须在 G2 替换。
- 邮箱仅允许 `example.com`；不得出现真实姓名、电话、学校、公司。
- 允许扩展字段，但需保持向后兼容并在 `STATUS.md` 记录；删除或重命名字段必须先更新本规格。
- 头像、封面等资源路径必须指向本地 `public/`，不得使用远程 URL。

## 6. 体验底线（必须满足）

1. 首屏 10 秒内说清"这是谁的什么"。
2. 每个交互都有可见入口、可见退出方式；无死胡同。
3. 键盘可完成主线浏览（Tab 焦点可见、Esc 可关闭浮层）。
4. 375px 宽度下主要模块可用，无横向滚动。
5. `prefers-reduced-motion: reduce` 时关闭非必要动画。
6. 不自动播放音频；刷新后不出现布局错乱或空白。
7. 首次访问引导不超过 3 步，且可跳过。

## 7. 性能与素材

- 首屏传输（JS+CSS+字体+首屏图片，未压缩）≤ 2MB；LCP 在中端移动网络下目标 < 2.5s。
- 图片优先 SVG/WebP；头像与封面使用自绘、生成或 CC0 素材，并在 `docs/SUBMISSION.md` 记录来源。
- 不用外部字体 CDN；需要字体则本地子集化，或使用系统字体栈。

## 8. 隐私与合规

- 人设、经历、项目全部虚构；邮箱仅 `example.com`。
- 作品帖与截图不得出现真实个人信息。
- 提交前由用户完成天池实名认证与阿里云大学生认证。

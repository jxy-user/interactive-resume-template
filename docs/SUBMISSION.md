## 作品帖正文（可直接粘贴）

### 标题

【LifeHack】此人在展 —— 一条走不到头的手绘画廊，每一扇门后是一个人生切片

### 一句话

把一份简历，做成一条白色手绘素描的无尽长廊：墙上挂着门、窗与画框，走近时黑白线稿被暖色晕染上色，推门而入，就是另一个世界。

### 自我介绍

> （请替换为你自己的话）我是一名在校学生，喜欢把"信息"做成"空间"。这次想把大家都会写、却大多很难看的简历，做成一间可以走进去的展厅。

### 作品是什么

一个开箱即玩的交互式简历网站模板。打开后是一条手绘素描风格的走廊，两侧墙上交替挂着「门 / 窗 / 画框」，每一扇都对应简历的一个部分——关于、教育、经历、技能、项目、联系。

- 鼠标**悬停**时，黑白线稿被暖色/彩色慢慢"上色"，移开又褪回素描。
- **点击**门、窗或画框，镜头会**推近撞进去**，走进该部分的"另一个世界"：
  - 项目：挂绳上悬着的黑白画，点开弹出详情卡；
  - 技能：悬浮的画布，点开看技能与熟练度；
  - 关于：一位手绘少年站在光里；
  - 联系：海边栈道与指路的木牌。
- 走廊尽头只有一团光，没有出口——像一条走不到头的长廊。

站内是**虚构人设**（林知远），完整演示所有交互；任何人克隆项目后，**只改 `public/resume-config.json` 一份文件**，就能变成自己的简历。

### 为什么做

简历几乎人人都有，但大多数人做出来的是 PDF 或千篇一律的模板页。学生和应届生尤其缺一个"拿得出手、又不用会设计"的个人主页。我们想证明：一份简历也可以有**空间感、情绪与一点点魔法**——而这一切，只需改一份 JSON。

### 怎么用（5 步）

1. 打开公网链接，进入《此人在展》的**无尽长廊**。
2. 鼠标移到墙上的**门 / 窗 / 画框**上，看黑白线稿被暖色**上色**。
3. **点击**任意一个，镜头推进，走进对应的**房间**（关于 / 教育 / 经历 / 技能 / 项目 / 联系）。
4. 在房间里继续探索：项目房间点画看**详情卡**，技能房间点**悬浮画布**，联系房间点**海边路牌**。
5. 点左上「返回走廊」回到长廊，继续探索；右上角可**开/关环境音**（实时合成，点击才发声）。

作品帖按真实分工书写，未夸大 Qoder 的代码贡献。

### 素材来源

- **全部素材为程序生成**：画面用 SVG 矢量绘制，画作、云、盆栽、纸张纹理均由代码生成；环境音用 Web Audio API 实时合成。
- **无外部图片 / 音频 / 字体 CDN**，字体使用系统字体栈；人设为虚构，邮箱仅 `example.com`。
- 技术栈：Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 + Framer Motion，纯前端静态导出（`output: "export"`），无后端、无登录、无数据库。

### 如何复用到你自己

1. 克隆仓库，`npm install`，`npm run dev`。
2. 只修改 `public/resume-config.json`（姓名、简介、教育、经历、技能、项目、联系）。
3. `npm run build` 生成 `out/`，部署到任意静态托管。
